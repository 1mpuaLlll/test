## 🌟 Features

### 💬 Advanced Messaging
- **Text Messages** with rich formatting (bold, italic, code blocks)
- **Voice Messages** with waveform visualization
- **Video Messages** up to 5 minutes
- **Group Chats** supporting up to 1,000 participants
- **Message Reactions** with emoji support
- **Edit & Delete** messages with full history

### 🔐 Security & Privacy
- End-to-end encryption for all messages
- Secret chats with self-destruct timers
- Two-factor authentication
- Secure file transfers up to 2GB

### 🎨 NFT Integration
- **NFT Profile Badges** - Display your favorite NFTs (e.g., #111)
- **3D NFT Gallery** in user profiles
- **NFT Gifting** - Send NFTs directly in chats
- **NFT Stickers & Emojis** - Custom NFT-based reactions
- **Transaction History** - View NFT transfer history

### 💎 Premium Subscriptions

**BASE (Free)** - Basic messaging + NFT badge viewing + 5GB storage

**PREMIUM ($9.99/mo)** - Custom NFT badges + 50GB storage + Priority support

**VIP ($29.99/mo)** - Holographic avatars + Exclusive NFTs + Personal manager

### 🌐 Web3 Integration
- MetaMask wallet connection
- Phantom wallet support
- NFT viewing from OpenSea, Rarible
- Ethereum & Polygon support

## 🚀 Quick Start

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The app will be available at `http://localhost:5173`

## 📁 Project Structure

```

├── components/          # React components
│   ├── auth/           # Authentication

│   ├── common/         # Reusable UI

│   ├── Welcome.tsx     # Registration
```
